# Font / Fonts

**Italiano** — WyrmUrbiGen usa solo i font di questa cartella, così funziona allo stesso modo su ogni computer.

> **Questi font non ricadono nella licenza GPL 3.0 di WyrmUrbiGen.** In particolare Sebaldus-Gotisch e Crimson Text mantengono le loro condizioni, indicate qui sotto, come gli altri font della cartella.

| File | Uso | Licenza |
|---|---|---|
| `DejaVuSansMono.ttf`, `DejaVuSansMono-Bold.ttf` | le mappe | `LICENSE-DejaVu.txt` (Bitstream Vera / DejaVu, libera) |
| `DejaVuSans.ttf` | i simboli nel libro PDF (frecce, ✓, muri) | `LICENSE-DejaVu.txt` |
| `CrimsonText-*.ttf` | il testo del libro PDF | `LICENSE-CrimsonText.txt` (SIL Open Font License 1.1) |
| `Sebaldus-Gotisch.ttf` | i titoli del libro PDF | © Typographer Mediengestaltung 2002, digitalizzato da Dieter Steffmann (www.steffmann.de); il file non contiene una licenza |

**Sebaldus-Gotisch** è distribuito gratuitamente dall'autore sui siti di font; il file riporta «All rights reserved» e non include un testo di licenza. Se manca da questa cartella, il programma lo segnala con un errore e non crea il libro PDF (le mappe sì).

---

**English** — WyrmUrbiGen only uses the fonts in this folder, so it works the same on every computer.

> **These fonts are not covered by WyrmUrbiGen's GPL 3.0 license.** In particular Sebaldus-Gotisch and Crimson Text keep their own terms, listed below, like the other fonts in this folder.

| File | Used for | License |
|---|---|---|
| `DejaVuSansMono.ttf`, `DejaVuSansMono-Bold.ttf` | the maps | `LICENSE-DejaVu.txt` (Bitstream Vera / DejaVu, free) |
| `DejaVuSans.ttf` | symbols in the PDF book (arrows, ✓, walls) | `LICENSE-DejaVu.txt` |
| `CrimsonText-*.ttf` | the text of the PDF book | `LICENSE-CrimsonText.txt` (SIL Open Font License 1.1) |
| `Sebaldus-Gotisch.ttf` | the headings of the PDF book | © Typographer Mediengestaltung 2002, digitized by Dieter Steffmann (www.steffmann.de); the file carries no license |

**Sebaldus-Gotisch** is given away for free by its author on font sites; the file says "All rights reserved" and comes with no license text. If it is missing from this folder, the program reports an error and doesn't make the PDF book (the maps are still made).
